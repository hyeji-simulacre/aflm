### 이 사이트는 어떻게 만들어졌나

프레임워크를 쓰지 않았습니다. HTML과 CSS를 손으로 썼고, Node 표준 모듈만으로 정적 파일을 만듭니다. 목록 배치와 화면 대응은 전부 CSS가 하고, 브라우저에서 도는 JavaScript는 없습니다. JavaScript를 꺼도 163편이 그대로 읽힙니다.

2026년 8월 8일 HTML의 날 서울에 다녀온 뒤, 5년 동안 Notion에 쌓아온 기록을 직접 만든 웹사이트로 옮겼습니다.

#### 구성

| 부분 | 내용 |
|------|------|
| 원본 | Notion 데이터베이스 내보내기. CSV와 개별 문서를 그대로 저장소에 보관 |
| 데이터 | `movies.json` 한 파일. 기록마다 값의 출처를 함께 적어 사람이 쓴 값과 API가 채운 값을 구분 |
| 생성 | Node 스크립트가 JSON을 읽어 목록, 분류별 목록, 편별 상세, 분류 색인을 만듦 |
| 배치 | CSS Grid. 첫 대사 길이로 카드가 차지할 행 수를 미리 계산해 넣음 |
| 입력 | 영화 제목을 검색해 메타데이터를 채우고, 사람은 첫 대사와 화법 분류만 입력 |
| 저장 | 새 기록은 GitHub에 커밋됨. 커밋 이력이 그대로 변경 이력이자 백업 |
| 배포 | Vercel |

#### 영화 정보

| 출처 | 쓰임 |
|------|------|
| TMDB (The Movie Database) | 국외 영화의 제목, 개봉일, 감독, 장르, 포스터 |
| KMDb (한국영상자료원 한국영화데이터베이스) | 한국 영화의 제목, 제작연도, 감독, 포스터 |

제목을 한국어, 영어, 제작국 언어 어느 쪽으로 넣어도 두 곳을 함께 찾습니다. 후보는 사람이 직접 고릅니다. 자동으로 확정하지 않습니다. 잘못 짝지어진 정보가 아카이브에 섞이면 되돌리기 어렵기 때문입니다.

찾지 못한 값은 비워 둡니다. 그럴듯한 값을 지어내지 않습니다.

이 사이트는 TMDB의 인증을 받거나 승인을 받은 것이 아닙니다.
